# CareerFlow Job Capture extension

1. Start the CareerFlow API on `http://localhost:8000`.
2. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this folder.
3. Open a job page, open the extension, and connect with the same CareerFlow account.
4. Use **Save to CareerFlow** for one-click capture. Keep automatic capture enabled to save when an application form is submitted.

The extension stores only the short-lived CareerFlow access token in Chrome extension storage. It never stores the user's password.
